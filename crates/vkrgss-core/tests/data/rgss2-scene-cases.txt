#
#   topic NAME
#   sprite ID VIEWPORT|-          plane ID VIEWPORT|-          viewport ID X Y WIDTH HEIGHT
#   set ID PROPERTY VALUE...      a number is truncated where the property holds an integer
#   flash ID DURATION nil|R G B A
#   update ID
#   clear                         disposes everything
#   frame DIGEST [DIGEST]         FNV-1a, 64 bits, over red, green and blue of every pixel
#
# Bitmaps, by name (x and y of a texel; `&` on the low 8 bits):
#   bg                 544 by 416, with X = x & 63, Y = y & 63:
#                      (X * 4 + Y, Y * 4 + 17 * X, X * Y + 3 * X + 60, 255)
#   cb_o, cb_a         256 by 8; row y is the y-th of (x, 0, 0), (0, x, 0), (0, 0, x),
#                      (x, 255 - x, 128), (x, x / 2, 255 - x), (255 - x, x, x * 3), (x, x, x),
#                      (x * 7, x * 13, x * 29); alpha 255 for `o`, x * 5 + y * 37 for `a`
#   pat_W_H_K_S        (x * 9 + y * 3 + S * 31 + 10, y * 13 + x * 2 + S * 17 + 20,
#                      x * 5 + y * 7 + S * 11 + 90), alpha 255 for K `o`,
#                      x * 29 + y * 53 + S * 7 + 40 for K `a`
