# Scenes of windows of RGSS3 with the pictures of the model of the window measurement of
# 2026-10-13 on the original runtime of VX Ace (`ace-v1-window-model.py`; RGSS300.dll 3.0.0.1
# and RGSS301.dll 3.0.1.1 gave the same pictures, and the model draws all 1185 captures without
# a wrong pixel): a selection of the case files of that measurement, the first and the last
# scene of each. The format is that of `vkxp_core::test_support::window_cases`. Every bitmap is
# made by a formula, and the digest of a frame is that of the picture the model draws.
#
# By case file:
#   a1    the cursor: its pieces, its place with origin and paddings
#   a2    the tone on the background, open and opening
#   a3    the paddings on contents, cursor and arrows; arrows_visible
#   a4    the cursor where cursor_rect less the origin is negative
#   a5    the places of arrows and pause sign with odd and negative sizes
#   a6    which calls show the contents and which build the bitmaps
#   a7    the default z among sprites and viewports, Window.new(x, y, width, height)
#   a8    small windows, windows without area
#   a9    skin and contents nil and disposed
#   a11   skins that cut the cursor block
#   a12   skins smaller than the layout
#   a13   the cursor far left of and above the origin
#   a14   the placed cursor in a window that grows and shrinks
#   a15   the arrows with paddings
#   a16   which calls decide the arrows
#
# Case files without a scene here: there is no a10; `rtp` reads the window skin of the
# run-time package from a file, which no formula makes.
